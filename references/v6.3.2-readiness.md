# v6.3.2 — Benchmark Readiness & Shared Asset Contract

## What is fixed

1. **Missing required regions cannot receive a scoped VERIFIED result**, even when the remaining assertions exceed 95% evaluability. `evaluate.mjs` lists `missingRequiredRegions`. Optional regions require explicit `required:false`; blank/missing selectors are not grounds for waiving scope.
2. **Fonts:** `capture-runtime.mjs` uses Chromium CDP `CSS.getPlatformFontsForNode` to identify fonts that actually rendered glyphs. A CSS `font-family` declaration or `document.fonts.check()` alone is not proof of the used typeface. Mixed or unavailable font evidence remains `NOT_EVALUABLE`. This is a Chromium-specific verification; it does not establish iOS/Safari typography.
3. **Rendered geometry:** sticky elements remain in flow; block/flex/grid track comparison follows v6.3.1 rules. The collector waits (bounded) for images, records asset load failure, and optionally performs two stability captures. Warnings and incomplete mappings prevent an unqualified runtime result.
4. **Original vs substitute imagery:** validate a private, pre-frozen asset pack with `asset-pack.mjs`. All A/B/C runs receive **the same files and manifest SHA**, with verified dimensions, file bytes, license and asset IDs. Substitutes are valid for layout, loading, fit and *shared asset usage* checks, but **never count as original Figma photo/pixel fidelity**.
5. **Actual browser test:** `tests/v6.3.2-browser-selftest.mjs` exercises Chromium DOM + CDP font lookup, placeholder values, sticky in-flow gaps, image load, missing CTA, and deliberately wrong font/gap/asset cases. `--fixture-html` mode is explicitly `ISOLATED_HTML_FIXTURE`; it cannot be used to certify the real application. Real Vue runtime still requires `--url http://localhost:...`.

## Asset pack (private project files)

Place `images/hero.webp`, etc. and a `pack.json` next to those files. Start from `assets/v6.3.2-asset-pack.template.json` but fill actual hashes and dimensions. Use assets you are authorized to use; never pretend an unrelated photo is the Figma original. Keep actual photographs/screenshots/credentials out of the public skill Git repository.

```bash
SKILL=/path/to/codex-pm-killer
node "$SKILL/benchmarks/v6.3/asset-pack.mjs" \
  --manifest .design-qa/algolia/assets/pack.json \
  --root .design-qa/algolia/assets \
  --out .design-qa/algolia/asset-lock.json
```

Each relevant image in A/B/C must have the agreed `data-benchmark-asset-id="hero"`; add an assertion `{"property":"asset_pack_id","expected":"hero"}` and a compatible `asset_kind`, `image_loaded`, `object_fit` when observed. The pack lock proves bytes and image dimensions. The runtime check proves the linked ID was rendered. It **cannot certify original photo equivalence or image pixel similarity**. File names, dimensions, aspect ratios and styling should be frozen before the experiment.

## Runtime measurement

```bash
node "$SKILL/benchmarks/v6.3/capture-runtime.mjs" \
  --url http://localhost:5173 \
  --mapping .design-qa/algolia/mapping.json \
  --out .design-qa/algolia/runtime.json \
  --width 375 --height 1069 --assert-stable
```

If the host cannot navigate to localhost, test the collector on a synthetic local HTML string using `--fixture-html local-test.html` but **do not treat this as live Vue QA**. Synthetic vs real runtime is recorded in `captureEnvironment`.

## Pre-paid benchmark readiness

Do not call paid APIs until independent evidence collection, a real Chromium browser smoke, shared asset freeze and original combined $5 approval have been checked.

```bash
node "$SKILL/benchmarks/v6.3/readiness-gate.mjs" \
  --gold-lock .design-qa/algolia/gold-lock.json \
  --asset-lock .design-qa/algolia/asset-lock.json \
  --mapping .design-qa/algolia/mapping.json \
  --approval .design-qa/algolia/approved-budget.json \
  --browser-report .design-qa/algolia/browser-smoke.json \
  --out .design-qa/algolia/readiness.json
```

- `BLOCKED` / nonzero exit -> **no new paid runs**.
- `READY_WITH_SUBSTITUTES` -> experiment may measure **layout and asset integration only**; original photo fidelity must stay NOT_EVALUABLE.
- `READY` -> supplied records meet preflight constraints; it does **not** independently prove Figma measurement, login, browser permissions or invoice totals.
- Gold `FROZEN_RECORDED_EVIDENCE`, 150 frozen assertions, required-region inventory, real browser smoke, font proof, asset lock, and approval record are all mandatory.

The readiness gate consumes evidence reports; it does not authenticate the person who recorded them. Always carry a verified, private original user-approved budget; no editing cap from $5 to $10 without approval.
