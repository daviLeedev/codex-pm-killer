# v6.3.1 Benchmark Verification Protocol

## Why this patch exists

The Nov 12 Home benchmark reported A 113/16/21, B 133/11/6, C 135/9/6 (MATCH/MISMATCH/NOT_EVALUABLE). These results were from v6.3.0 and **must remain frozen**. Review found incorrect horizontal gap calculation when a block element's default `flexDirection: row` was applied, and search placeholder text/color collected as normal text/color.

## Changes and evidence requirements

- **Block / Flow-root:** compare true vertical boundary distances of participating in-flow block children. Inline/positioned ambiguities remain NOT_EVALUABLE.
- **Flex:** use row/column direction and only compare adjacent siblings in the same actual track.
- **Grid:** require a Gold assertion `axis: "row"` (vertical distance) or `axis: "column"` (horizontal distance). Without it return NOT_EVALUABLE.
- **Placeholder:** capture actual HTML placeholder text and getComputedStyle(input, "::placeholder").color in the real browser. Do not equate input text color with placeholder color.
- **Image / icon fidelity:** `asset_kind` can distinguish vector from raster/photo and placeholder. It does **not** prove exact file, colors, path outline or visual similarity; compare real asset content separately when allowed.
- **Budget:** user-approved aggregate $5 is not $5 per A/B/C. Verify external host config and ledger against private original approval evidence. The script checks operator-supplied data only, not billing.
- **History:** release notes are code history, benchmark run entries are experiment history. Store privacy-reviewed aggregates in `benchmarks/history/`, raw evidence private.

## Validated offline

Run:

```bash
node tests/v6.3-selftest.mjs
node tests/v6.3.1-selftest.mjs
node tests/v6.3.1-policy-selftest.mjs
node tests/v6.3.1-history-selftest.mjs
node tests/v6.3-budget-selftest.mjs
```

The synthetic tests demonstrate error detection for controlled values; they do not claim live Algolia or model success.

## How to perform a real re-evaluation

1. Retain the v6.3 Gold assertions and SHA untouched.
2. Confirm direct accessible viewer and evidence hashes for the specific Home version. If unavailable, report `BLOCKED` / `NOT_EVALUABLE`.
3. Re-capture all A/B/C actual Vue pages under their frozen original conditions using the v6.3.1 `capture-runtime.mjs`. Original report screenshots are not automatically equivalent to these DOM measurements.
4. Re-run the patched evaluator with the same frozen 150 item denominator and new measured runtime facts; issue fresh run IDs and include old/fixed score delta and changed assertion IDs. For Grid, declare the correct axis only if supported by viewer evidence.
5. Check image/photo and font fidelity independently; never promote a geometry match into image fidelity.
6. Report counts, trustworthy coverage and unresolved IDs separately. Do not claim 95% until evidence-bound evaluation actually reaches it.
7. Verify approval and budget ledger; store private evidence, redact and validate public history summary before publishing.

Caveats: no connected browser or API key is required to execute the offline tests. Actual end-to-end Figma/browser work needs a capable host and authenticated read-only viewer. Prior raw ZIP is not committed publicly.
